# プロンプト: 早見表の画像

早見表は4つ目の添付です。24個の名前を動画と同じ順に1枚にまとめ、保存してもらうための画像です。
文字を描ける画像生成AIを使います。`<...>` を埋めてください。

構成の参考画像として、`examples/camera-moves/ja/cheatsheet.png`（線画アイコン）か `examples/motion-graphics/ja/cheatsheet.png`（カラーのサムネ）を添付できます。

## 依頼文

```
<言語>の早見表（チートシート）の画像を作ってください。
<参考画像を添付する場合: 構成と余白は参考画像に合わせ、文字は下の文言だけを使う。
参考画像の文字は写さない。>

## 出力
- 縦横比 8:9（例 1024x1152）。最初から8:9の構図で全体を収める（切り抜き・余白足しを前提にしない）
- 3案作る。案ごとに余白・文字の大きさ・アイコンの描き方を少し変える。文言は3案とも同じ

## 構成
- 最上部: 太い大見出し「<題>」、その下にグレーの副題「<副題>」
- 白〜ごく薄いグレーの地。区分ごとに角丸の枠（薄いグレーの線）。区分見出しは差し色
- 各行は列のそろった表にする:
  アイコン → 番号（差し色）→ 太字の名前 → <2行目・グレー> → グレーの一言説明
  （英語以外の一式では、2行目は全行とも英語名）
- 最下段: 薄いグレーの帯に一言
- <色: 例 青1色＋黒＋グレーだけ。絵文字・写真・グラデーションは使わない>
- 8:9に24行を収める。行間はやや詰めてよいが、文字は潰さずはっきり読める大きさで

## 文言（一字一句このまま。言い換え・省略・追加は禁止。「｜」は列の区切りで画像には描かない）
題: <題>
副題: <副題。例「動画の番号 → AIに伝える名前」>
区分見出し1: <動画 1/3　区分名　01–08>
01｜<名前>｜<2行目>｜<説明文>
…
08｜…
区分見出し2: <動画 2/3　区分名　09–16>
09｜…
…
区分見出し3: <動画 3/3　区分名　17–24>
17｜…
…
24｜…
最下段の一言: <名前に『A・B・C』を添えると精度が上がる：例 ／ 例 ／ 例>

## アイコン
<下のA案かB案。行ごとに1つずつ目安を書く>
```

### アイコンA案: 単純な線画

差し色1色の細い線画を、行ごとに小さな角丸の四角に入れます。**行ごとに描く物の目安を書く**こと。書かないと、別の行に同じようなアイコンが描かれます。

```
アイコン（差し色の線画・小さく単純に）:
01 <名前> = <描く物。例「横向きの両矢印とカメラ」>
02 <名前> = <…>
…
向きが逆になっている2つ（前／後、始まり／終わり、左／右）は、向きをはっきり書く。
例「音の帯が映像の帯より先（音が先行）」
```

### アイコンB案: カードを縮めたカラーのサムネ

カードに色を使っている一式に向きます。各カードの見せ場のコマを1枚ずつ取り出し、番号を付けて並べた画像（`--sheet` のコマから作れます）を添付して、こう書きます:

```
左端の列は線画ではなく、動画の各カードを小さく再現したサムネにする。
添付の cards.png は各カードの見せ場のコマで、01〜24の番号付き。
- 24個とも位置と大きさは同じ（横長の小さな角丸の四角・左端をそろえる）
- 使う色はこれだけ: <パレットと色コード>。フラットな塗り。グラデーション・写真・絵文字は使わない
- とても小さいので大きく単純化し、主役の形を太く大きく描く。サムネの中に細かい文字は入れない
  （下で指定した1〜3文字まで）
01 <カード01から描く物>
…
24 <…>
```

## できたら全部のマスを確かめる

画像生成AIは、今でも誤字・文字の入れ替わり・行の抜けを出します。実際に「隅」が「隣」に、「額縁」が「額線」に、『』が「」に化けました。

1. いちばん良い案を選び、原寸に拡大して、全行・区分見出し・題・副題・最下段を一覧と照らし合わせます。番号が01〜24で、飛びや重複がないかも見ます。
2. アイコンが名前に合っているか確かめます。特に向きが逆の組（前／後、始まり／終わり、左／右）。
3. 崩れていたら、崩れた行だけを指定して直させます（「ほかは一切変えない。08行の説明文は『…』にする」）。全体を作り直させると、ほかの行が崩れがちです。
4. 何回か直させても同じ行が崩れるなら、選択肢は2つです。いちばん良い案を使い、残った崩れを利用者に一覧で伝えるか、同じ文言・同じ構成をHTMLで描いて画面を撮るか。どちらにしたかを利用者に伝えます。
5. 最後に1200×1350へ拡大・縮小し、動画と大きさをそろえます（8:9に近い 1182×1330 などで出てくることが多いです）。
6. 依頼文を画像の隣に保存しておきます。作り直すときに使えます。
