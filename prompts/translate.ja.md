# プロンプト: 同じ一式を別の言語で作る

既にある一式（見本でも、自分で作った物でも）の別の言語版を、コーディングAIで作ります。絵と動きはそのままで、言葉だけを替えます。
`<...>` を置き換えます。`<lang>` は `es`・`zh`・`fr` のような短い言語コードです。

```
このリポジトリの README.ja.md、PROMPT.ja.md、<元の index.html のパス> を読んで。

やりたいこと: この一式の<言語>版を、同じ絵と動きで作る。

1. <元のフォルダ>/index.html を <題材のフォルダ>/<lang>/index.html にコピーする。
2. 画面に出る文字だけを訳す: シリーズの題、PAGES（区分名）、ITEMS（名前と2行目）、
   カードの中に描かれた小さな文字（CELLS のコードの中の文字列を探す）。どの言語でも
   そのまま読まれる機材の表示（例「REC」「24mm」）は訳さない。
3. レイアウト・色・タイミング・描画のコードは変えない。
4. 名前は、<言語>の現場で実際に使われている呼び方にする。1つずつWebで確かめる。
   英語のまま使われていることも多い。その場合は英語のままにする。直訳の言葉を作らない。
   <言語>で俗語や失礼な意味にならないかも確かめる。<言語>が英語でなければ、全カードの2行目は英語圏の現場で実際に使われている
   英語名にする（訳した造語にしない）。
5. 書体: <言語>に別の文字（CJK・アラビア文字・タイ文字・デーヴァナーガリーなど）が要るなら、
   書体の定数をこの機械に入っている書体に替え、字が四角にならないことを確かめる。
   右から左へ書く言語なら、レイアウトを変える前に相談する。
6. 文字を収める: 名前はカードの幅で1行に。長すぎるなら、まず通用している短い呼び方を探す。
   文字を小さくするのは最後の手段で、そのときは24個まとめて小さくする。
7. 書き出して確かめる:
     node render.mjs <題材>/<lang>/index.html --all --sheet
   3枚のコマ一覧を自分の目で見る: 文字の欠け・重なり・字の抜け（四角）がないこと。
8. 報告: 24個の名前と説明文の対応表（元の言語 → <言語>）、自信のない物とその理由、使った書体。
```

そのあと `prompts/cheatsheet-image.ja.md` で早見表を作り、`prompts/review.ja.md` で、新しい言語の母語話者（またはその言語の母語話者として読むよう指示した評価役）に言い回しを見てもらいます。英語のカメラワーク版では、この確認で題・副題・最下段の一言・説明文5か所が直りました。
